The first SD card image of web888-ng: an open firmware for the Web-888
SDR that boots from its own microSD card. **A test image for owners
who have their Web-888 at hand.** It has run only in an emulator so
far; this release is how it gets onto real boards.

Your unit is not changed: everything is on the new card. To go back to
the stock firmware, power off and put your original card back in.

**How to try it:** [docs/testing-the-sd-image.md](https://github.com/jeskko/web888-ng-os/blob/v0.1.0/docs/testing-the-sd-image.md).
In short: write `web888-ng-sd-v0.1.0.img.xz` to a spare card of 2 GB or
more, set an admin password (and a static address if you need one) in
`web888.txt` on the card's `WEB888` drive, boot, and open
`http://web888.local:8073`.

## What's in it

* Boot loader: U-Boot 2026.01 (SPL with the PS7 setup of the open FPGA
  design, then U-Boot). It sets the ADC clock (Si5351, 122.88 MHz) and
  boots one of two system copies on the card, falling back to the other
  if one keeps failing.
* Linux 6.18 (AMD/Xilinx LTS) with the open `web888-sdr` driver and a
  device tree for the Web-888.
* The open FPGA bitstream (web888-ng-hw v0.2.0, 12 receivers).
* [web888d v0.5.0](https://github.com/jeskko/web888-ng/releases/tag/v0.5.0):
  the web receiver (waterfall, AM/SSB/CW/FM; listeners and skimmers
  share the bitstream's 12 receivers), FT8, FT4 and WSPR skimmers with
  PSKReporter and WSPRnet uploads, HPSDR Protocol 1 (SparkSDR, SDR++ and
  the like), admin pages.
* `web888.txt` on the card: admin password, DHCP or static network,
  hostname, an SSH key. `web888-setup.log` next to it says what was
  applied.

## Known limits

* **Not yet run on hardware.** The boot loader's memory and clock setup
  matches the stock firmware's, but this is the first time it meets a
  board. If the unit doesn't come up, a serial console log helps most.
* Assumes the usual 24.576 MHz reference for the ADC clock.
* Over plain HTTP the browser plays audio with about a quarter second
  more delay; the status bar links to the HTTPS address of the same page,
  which plays with less (the browser warns once about the unit's own
  certificate).
* No updates over the network yet: a new release means writing the card
  again (settings made in the admin pages are lost then; keep a copy of
  `web888.txt`).
* KiwiSDR clients and the stock firmware's extensions are not supported.

## Files

* `web888-ng-sd-v0.1.0.img.xz`: the card image; `.img.bmap` for
  `bmaptool`
* `SHA256SUMS`
* `web888-ng-sd-v0.1.0.spdx.json` and `.manifest`: the software in the
  image and its licences (SPDX). Sources: the recipes in this repository
  at the tag, and the upstream projects they name.

Please report what you find, working or not, as an issue in
[web888-ng-os](https://github.com/jeskko/web888-ng-os/issues): the
board's `hw_rev`, `web888-setup.log`, and what you tried.
