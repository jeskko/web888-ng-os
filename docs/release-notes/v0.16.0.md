**Signals explained, neural noise reduction (experimental), DGPS:**
web888d v0.18.0 adds an explanation for any signal you click and
labels for every signal in the waterfall. It also adds noise reduction
by small neural networks for SSB voice, CW and AM broadcasts, an
experimental generative voice restorer, and a DGPS beacon decoder. All
of these run in the listener's browser. This release also brings
Linux 6.18.65 and a CVE round. Test images, for owners who have their
Web-888 at hand.

**Updating from v0.9.0 or later:** the admin page's **Update** tab
offers v0.16.0 (it looks once a day, or press **Look for a release**):
**Install**, then **Reboot now**. The unit keeps its settings and goes
back to the previous system by itself if the new one doesn't come up
([docs/updates.md](https://github.com/jeskko/web888-ng-os/blob/v0.16.0/docs/updates.md)).

**From v0.3.0 to v0.8.0** (SSH, with an `ssh_key` in `web888.txt`):

```sh
rauc install https://github.com/jeskko/web888-ng-os/releases/download/v0.16.0/web888-ng-v0.16.0.raucb
reboot
```

Units on v0.1.0 or v0.2.0 write this card image instead (keep a copy of
`web888.txt`).

**New to web888-ng:** [docs/owner-guide.md](https://github.com/jeskko/web888-ng-os/blob/v0.16.0/docs/owner-guide.md).

## New since v0.15.0

* **web888d v0.18.0** (its release notes have the details):
  * **"What is this?":** shift-click a signal on the waterfall. The page
    listens for about 4 s and says what the signal is and why, from
    measured figures and a 25-class identifier.
  * **Signal labels** (Panels): every signal in the waterfall's view
    named on the spectrum.
  * **Neural noise reduction, experimental** (the Noise box's **NN**,
    marked *exp.*): for SSB voice, CW and AM broadcasts, with a strength
    slider. It takes noise away and never adds sound. The models are
    still being trained; later releases will change them.
  * **Gen, experimental** (beside NN in SSB voice): a generative restorer
    that rebuilds the voice. It sounds clearer but may now and then add
    sounds or words that weren't said; the decoders never hear it. It
    ships with the best weights measured so far.
  * **DGPS:** maritime DGPS beacons (283.5-325 kHz). The panel shows
    each beacon's station, health and position, each satellite's
    correction, and the beacon almanac. **Wide** skims 40 kHz at once.
  * **Twin passband tuning** (PBT 1/PBT 2, Shift), with passband changes
    faded in without a click. The page is tidied into fewer boxes.
  * Slow narrow FSK idents in the RTTY panel. TDF is shown as
    ALS162 (TDF).
* **The web UI is the release's own again:** v0.15.0 shipped web888d
  v0.16.0's UI by mistake, so its Time panel lacked the stations added
  in web888d v0.17.0. The image now also carries the model
  weights fetched on demand (Gen's `nrgen.bin`).
* **Linux 6.18.65** (from 6.18.64): fixes in ksmbd, inet fragments,
  shmem, filemap, large folio PTEs, the stack growth charge and overlayfs.
* expat 2.11.0; glibc at the head of release/2.43/master (a regcomp/
  regexec fix); CVE statuses for what doesn't apply to the image,
  among them expat's CVE-2026-137951 and -137992 (published
  2026-11-28; only dbus and avahi use expat, on their own config files)
  and eight libxml2 CVEs (only update-mime-database uses it).
  Four kernel CVEs remain open, with no fix in 6.18 yet.

Bitstreams are the same as in v0.15.0.

## Known limits

* NN and Gen are experimental (above). Gen's output is for listening,
  not proof of what was said.
* VHF (`band = vhf`) still needs testing against real signals or a signal
  generator (see v0.7.0's notes).
* The Update tab has installed updates in the emulator, not yet on a
  board; SSH (above) remains the way if it fails.
* The boot loader update (v0.10.0) has run in the emulator only. Writing
  it is optional.
* Kiwi clients get levels in dBFS unless `[kiwi] smeter_offset_db` is
  set: the dBm calibration hasn't been measured yet.
* Safe mode has run in the emulator, not yet on a board.
* Assumes the usual 24.576 MHz reference for the ADC clock.
* Over plain HTTP the browser plays audio with about a quarter second more
  delay. The status bar links to the HTTPS address (the browser warns once
  about the unit's own certificate).
* No Wi-Fi since v0.9.1.
* The stock firmware's extensions and the Kiwi browser UI are not
  included.
