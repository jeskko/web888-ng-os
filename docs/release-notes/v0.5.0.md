web888-ng's SD card image with web888d v0.8.0: **KiwiSDR clients**
(kiwirecorder, SuperSDR and other Kiwi software) can use the receiver.
Test images, for owners who have their Web-888 at hand.

**Updating from v0.3.0 or v0.4.0** (SSH, with an `ssh_key` in
`web888.txt`):

```sh
rauc install https://github.com/jeskko/web888-ng-os/releases/download/v0.5.0/web888-ng-v0.5.0.raucb
reboot
```

The unit keeps its settings and goes back to the previous system by
itself if the new one doesn't come up ([docs/updates.md](https://github.com/jeskko/web888-ng-os/blob/v0.5.0/docs/updates.md)).
Units on v0.1.0 or v0.2.0 write this card image instead (keep a copy of
`web888.txt`).

**How to try it:** [docs/testing-the-sd-image.md](https://github.com/jeskko/web888-ng-os/blob/v0.5.0/docs/testing-the-sd-image.md).

## New since v0.4.0

* **web888d v0.8.0** ([release notes](https://github.com/jeskko/web888-ng/releases/tag/v0.8.0)):
  the KiwiSDR protocol on the web port (8073).
  * Kiwi clients get audio (USB, LSB, CW, AM, SAM, IQ; plain or
    compressed) and the waterfall, and `/status` answers as on a Kiwi.
  * Point kiwirecorder at the unit as at a Kiwi:
    `kiwirecorder.py -s <unit> -p 8073 -f 7074 -m usb`. With a listener
    password, give it with `--pw`.
  * Each audio stream takes a receiver channel. When all are taken, the
    client is told the receiver is busy.
  * The `[kiwi]` settings (name, location, the dBm offset) are in the
    admin pages.

## Tested

In the emulator (web888-ng-hw `emu/tests/`):
* the image's boot through the boot ROM, both slots and `web888.txt`
  (`sd-image.sh`);
* **the update from the published v0.4.0 image to this release's bundle**
  (`ota.sh`): a streamed install, the reboot into the new slot, a power
  cut during an install, and a bad update rolled back.

web888d v0.8.0 has run on a Web-888 since 2026-11-11, chain-loaded rather
than from this card. kiwirecorder and SuperSDR were tried against it with
real signals.

## Known limits

* Kiwi clients get levels in dBFS unless `[kiwi] smeter_offset_db` is
  set: the dBm calibration hasn't been measured yet.
* Updates leave `BOOT.BIN` and `u-boot.img` alone (they aren't A/B); a
  release that needs new ones will say so.
* Assumes the usual 24.576 MHz reference for the ADC clock.
* With `bitstream = channelizer`, the bitstream setting in the admin pages
  has no effect (`web888.txt` decides).
* Over plain HTTP the browser plays audio with about a quarter second more
  delay. The status bar links to the HTTPS address (the browser warns once
  about the unit's own certificate).
* The stock firmware's extensions and the Kiwi browser UI are not
  included.

## Files

* `web888-ng-sd-v0.5.0.img.xz`: the card image; `.img.bmap` for
  `bmaptool`
* `web888-ng-v0.5.0.raucb`: the update bundle, for units on v0.3.0 or
  later
* `SHA256SUMS`
* `web888-ng-sd-v0.5.0.spdx.json` and `.manifest`: the software in the
  image and its licences (SPDX). Sources: the recipes in this repository
  at the tag, and the upstream projects they name.
