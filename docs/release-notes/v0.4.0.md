web888-ng's SD card image with web888d v0.7.0: a **phone layout**,
**frequency labels** and a **band ribbon**. It is also the first release
that a v0.3.0 unit can install over the network. Test images, for owners
who have their Web-888 at hand.

**Updating from v0.3.0** (SSH, with an `ssh_key` in `web888.txt`):

```sh
rauc install https://github.com/jeskko/web888-ng-os/releases/download/v0.4.0/web888-ng-v0.4.0.raucb
reboot
```

The unit keeps its settings and goes back to v0.3.0 by itself if the new
system doesn't come up ([docs/updates.md](https://github.com/jeskko/web888-ng-os/blob/v0.4.0/docs/updates.md)).
Units on v0.1.0 or v0.2.0 write this card image instead (keep a copy of
`web888.txt`).

**How to try it:** [docs/testing-the-sd-image.md](https://github.com/jeskko/web888-ng-os/blob/v0.4.0/docs/testing-the-sd-image.md).

## New since v0.3.0

* **web888d v0.7.0** ([release notes](https://github.com/jeskko/web888-ng/releases/tag/v0.7.0)):
  * **Phone layout:** the dial on top, the waterfall filling the screen
    with pinch to zoom, a thumb dock with the modes, the band picker and a
    VFO wheel.
  * **Frequency labels** along the top of the spectrum, chosen with the
    Labels button. Click one to tune there.
    * Shortwave broadcasts on the air now (EiBi's schedules).
    * Utility stations: time signals, maritime safety, VOLMET, weather
      fax.
    * Amateur activity frequencies.
    * The receiver's own list, which the admin uploads as CSV in the admin
      pages.
  * **Band ribbon** under the spectrum: the IARU region's amateur band
    plan in its segments, and the broadcast, maritime, aero and
    time-signal bands. Each listener can pick IARU region 1, 2 or 3.
  * New sessions start on 7.066 MHz LSB with a 960 kHz view.
* **One card image.** Every image has all the bitstreams. To use the
  experimental channelizer, set `bitstream = channelizer` in `web888.txt`;
  the separate `-channelizer` image of v0.2.0 and v0.3.0 is gone. An
  update keeps the unit's choice.

## Tested

In the emulator (web888-ng-hw `emu/tests/`):
* the image's boot through the boot ROM, both slots and `web888.txt`,
  once as shipped and once with `bitstream = channelizer`
  (`sd-image.sh`);
* **the update from the published v0.3.0 image to this release's bundle**
  (`ota.sh`): a streamed install, the reboot into the new slot, a power
  cut during an install, and a bad update rolled back.

web888d v0.7.0 has run on a Web-888 since 2026-11-04, chain-loaded rather
than from this card. The phone layout has been used on an iPhone.

## Known limits

* Updates leave `BOOT.BIN` and `u-boot.img` alone (they aren't A/B); a
  release that needs new ones will say so.
* Assumes the usual 24.576 MHz reference for the ADC clock.
* With `bitstream = channelizer`, the bitstream setting in the admin pages
  has no effect (`web888.txt` decides). On the channelizer, the 960 kHz
  starting view costs about 17 % of one CPU core (shared by everyone on
  it).
* Over plain HTTP the browser plays audio with about a quarter second more
  delay. The status bar links to the HTTPS address (the browser warns once
  about the unit's own certificate).
* KiwiSDR clients and the stock firmware's extensions are not supported.

## Files

* `web888-ng-sd-v0.4.0.img.xz`: the card image; `.img.bmap` for
  `bmaptool`
* `web888-ng-v0.4.0.raucb`: the update bundle, for units on v0.3.0 or
  later
* `SHA256SUMS`
* `web888-ng-sd-v0.4.0.spdx.json` and `.manifest`: the software in the
  image and its licences (SPDX). Sources: the recipes in this repository
  at the tag, and the upstream projects they name.
