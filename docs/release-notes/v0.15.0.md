**The receiver as a clock:** web888d v0.17.0 decodes the time-code
stations in reach (LF and HF) and hands them to chrony, so the unit keeps
time without the Internet, and can serve it to the shack over NTP. Test
images, for owners who have their Web-888 at hand.

**Updating from v0.9.0 or later:** the admin page's **Update** tab
offers v0.15.0 (it looks once a day, or press **Look for a release**):
**Install**, then **Reboot now**. The unit keeps its settings and goes
back to the previous system by itself if the new one doesn't come up
([docs/updates.md](https://github.com/jeskko/web888-ng-os/blob/v0.15.0/docs/updates.md)).

**From v0.3.0 to v0.8.0** (SSH, with an `ssh_key` in `web888.txt`):

```sh
rauc install https://github.com/jeskko/web888-ng-os/releases/download/v0.15.0/web888-ng-v0.15.0.raucb
reboot
```

Units on v0.1.0 or v0.2.0 write this card image instead (keep a copy of
`web888.txt`).

**New to web888-ng:** [docs/owner-guide.md](https://github.com/jeskko/web888-ng-os/blob/v0.15.0/docs/owner-guide.md).

## New since v0.14.0

* **web888d v0.17.0** (its release notes have the details). The
  stations are off by default: turn on `timecode.enabled` in the admin
  page's settings (with `station.locator` set, for the stations in
  reach and their paths); it costs about a tenth of a CPU core.
  * time-code stations decoded on the receiver, by region (`[timecode]
    region = "auto"`: those in reach of the station's locator): DCF77,
    MSF, RBU, TDF, the EFR teleswitch stations in Europe, WWVB in North
    America, JJY and BPC in East Asia, and on HF WWV/WWVH, BPM and RWM;
  * their offsets combined and handed to chrony through the socket that
    v0.14.0 set up; while NTP answers it leads, without the Internet the
    stations keep the clock (typically a few tenths of a millisecond,
    less sure minutes pooled at dusk and dawn);
  * the admin page's **Clock** tab: chrony, the stations, what goes to
    chrony;
  * **NTP for the local network** (Clock tab, off by default): chrony
    answers devices on private and link-local addresses, for a station
    where the Internet is poor. The switch explains the risks first.
* **chrony** rate-limits NTP clients (a client asking more often than
  every 8 s on average has requests dropped); nothing is served unless
  the switch above is on.
* The owner guide's §5 has a part on the clock without the Internet.

Kernel, packages and bitstreams are the same as in v0.14.0.

## Tested

In the emulator (web888-ng-hw `emu/tests/`), on this release's build:
* the image's boot through the boot ROM, both slots, `web888.txt`, safe
  mode, chronyd with its socket, and NTP for the LAN switched on and off
  from the admin API, with an NTP request from the guest's LAN address
  answered (`sd-image.sh`, 63 checks; its first run found the switch
  saved but not applied, fixed in web888d before the release);
* **the update from the published v0.14.0 image to this release's
  bundle** (`ota.sh`, 21 checks), with a power cut mid-install and a bad
  update rolled back.

On a Web-888 (the developer's remote unit, chain-loaded, chrony 4.8 as
in the image): web888d with the time-code stations since 2026-11-19,
including a 24-hour run with them as chrony's only source (90 % of the
time within 0.5 ms of NTP), and this web888d build since 2026-11-22.
This image itself has run in the emulator only.

## Known limits

* VHF (`band = vhf`) still needs testing against real signals or a signal
  generator (see v0.7.0's notes).
* The Update tab has installed updates in the emulator, not yet on a
  board; SSH (above) remains the way if it fails.
* The boot loader update (v0.10.0) has run in the emulator only. Writing
  it is optional.
* Kiwi clients get levels in dBFS unless `[kiwi] smeter_offset_db` is
  set: the dBm calibration hasn't been measured yet.
* Safe mode has run in the emulator, not yet on a board.
* Assumes the usual 24.576 MHz reference for the ADC clock.
* Over plain HTTP the browser plays audio with about a quarter second more
  delay. The status bar links to the HTTPS address (the browser warns once
  about the unit's own certificate).
* No Wi-Fi since v0.9.1.
* The stock firmware's extensions and the Kiwi browser UI are not
  included.
